Politique de Confidentialité

Bienvenue sur BoutiquePro, une solution SaaS de gestion de boutique alimentaire éditée par Fadir.

BoutiquePro permet notamment aux commerçants de gérer leurs ventes, leur encaissement, leurs stocks, leurs crédits clients, leurs dépenses et leur caisse.

La présente Politique de confidentialité explique quelles données peuvent être collectées, comment elles sont utilisées, comment elles sont protégées et quels droits peuvent être exercés par les utilisateurs.

En utilisant BoutiquePro, vous reconnaissez avoir pris connaissance de la présente Politique de confidentialité.

03

Connexion avec Google

BoutiquePro peut permettre aux utilisateurs de créer un compte ou de se connecter à l'aide de Google OAuth.

Lorsque vous choisissez cette méthode de connexion, Google peut transmettre à BoutiquePro certaines informations associées à votre compte Google, conformément aux autorisations accordées.

Ces informations peuvent notamment comprendre :

  • votre nom ;
  • votre adresse e-mail ;
  • votre photo de profil, lorsque celle-ci est fournie et autorisée ;
  • un identifiant associé à votre compte Google.

Ces informations sont utilisées principalement pour :

  • créer votre compte BoutiquePro ;
  • vous authentifier ;
  • sécuriser votre compte ;
  • vous permettre d'accéder au service.

BoutiquePro n'utilise pas les données obtenues via Google à des fins incompatibles avec les finalités pour lesquelles elles ont été collectées.

07

Fonctionnement Offline-First

BoutiquePro est conçu selon une approche Offline-First.

Certaines fonctionnalités peuvent donc continuer à fonctionner lorsque l'utilisateur ne dispose pas temporairement d'une connexion Internet.

Dans ce contexte, certaines données peuvent être stockées temporairement sur l'appareil utilisé.

Lorsque la connexion Internet est disponible, les données concernées peuvent être synchronisées avec les services utilisés par BoutiquePro.

L'utilisateur doit protéger son appareil et son compte afin d'empêcher tout accès non autorisé.

Les données qui n'auraient pas encore été synchronisées peuvent être affectées par la perte, la détérioration ou la réinitialisation de l'appareil.

  • de sécurité ;

Ces prestataires peuvent accéder aux données uniquement dans la mesure nécessaire à la fourniture de leurs services.

Des données peuvent également être communiquées lorsqu'une telle communication est nécessaire pour :

  • prévenir ou détecter une fraude, une attaque ou une utilisation abusive.
